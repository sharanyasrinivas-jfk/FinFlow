# User journey

> Journey, pain points and opportunities are **[HYPOTHESIS]** drawn from the simulated funnel, not from user research. Validate with session recordings and interviews.

| Stage | Applicant does | Pain point (baseline) | Redesign response | Simulated step conversion (baseline -> pilot) |
|---|---|---|---|---|
| Visited -> Started sign-up | Lands, decides to apply | Unclear what is needed | Checklist of what to have ready | 61% -> 67% |
| Started -> Created account | Enters contact details, password | Long form | Progressive profile (defer optional fields) | 80% -> 86% |
| Account -> Submitted documents | Photographs ID, selfie, address proof | Blurry, glare, expired ID; no feedback until review | Live quality checks, examples, specific errors, retake | 70% -> 82% |
| Submitted -> Passed verification | Waits for review | ~25h median, no status | Status tracker with SMS/email, ranges not exact times | 78% -> 88% |
| Passed -> Completed profile | Fills remaining details | Long wait before this step | Progressive profile | 84% -> 90% |
| Completed -> Funded | Makes first deposit | Drift after a long process | Status and reminders | 73% -> 78% |

## Rejection and recovery path
1. Applicant is rejected (e.g. name mismatch). **Baseline:** generic message, documents discarded, restart.
2. **Redesign:** the reason is named, saved documents are kept, and the applicant fixes the single issue in place (prototype in the lab page).

## Emotional curve [HYPOTHESIS]
Motivated at sign-up, anxious while photographing documents, frustrated at rejection, uncertain while waiting. The biggest relief opportunities are *before* submission (prevent errors) and *after* (show status).
